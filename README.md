# 豆包录音转写助手

把录音拖入 Windows 窗口，借助本机已安装的豆包输入法组件进行在线识别，保存为 TXT。

**第三方实验性工具，与豆包官方无关联。当前为预览版，仅适配豆包输入法 0.9.0.0 的指定组件。** 输入法或服务端更新都可能使识别失效；这不是豆包公开支持的文件转写 API。

[下载安装包](https://github.com/CPZIOO4/doubao-file-transcriber/releases) · [报告问题](https://github.com/CPZIOO4/doubao-file-transcriber/issues/new/choose) · [构建说明](docs/BUILD.md) · [隐私与数据处理](docs/PRIVACY.md)

## 能做什么

- 拖入一个或多个录音文件，按顺序在后台处理。
- 窗口可隐藏到托盘，转写时无需保持输入框焦点。
- 自动检测豆包安装位置与组件指纹：未安装给出官网入口，未适配给出明确提示。
- 默认把 UTF-8 TXT 保存到用户的“文档/豆包转写结果”；可选择其他目录，同名文件自动编号。
- 长录音优先在停顿处分段；识别失败时尽量保留已完成部分。
- 不使用虚拟声卡，不切换默认音频设备，不模拟按键或读取剪贴板。

## 使用条件

| 项目 | 要求 |
| --- | --- |
| 系统 | Windows 10 1809+ / Windows 11，x64；.NET Framework 4.7.2+ |
| 豆包输入法 | 自行从[官网](https://ime.doubao.com/)安装并完成首次设置；目前验证为 0.9.0.0 的固定组件 |
| 网络 | 必须联网，音频送至豆包在线服务处理 |
| 音频格式 | WAV、MP3、M4A 等，实际支持取决于 Windows Media Foundation 和系统解码器 |
| 额外运行时 | 安装包自带 Python；无需另装 Python、FFmpeg 或虚拟声卡 |

Windows N 版可能需要媒体功能包。没有适配当前豆包版本时，请等待本工具更新，不要替换或降级正常使用的输入法。项目不提供豆包程序或 SDK 下载。

## 快速开始

1. 在 [Releases](https://github.com/CPZIOO4/doubao-file-transcriber/releases) 下载 `doubao-file-transcriber-1.0.0-preview.1-windows-x64-setup.exe`。
2. 安装后打开“豆包录音转写”，等待兼容性检测。
3. 先拖入一小段不含敏感信息的录音测试。检测通过后会自动开始识别。
4. 完成后双击列表项目打开 TXT，或点击“打开结果目录”。

关闭或最小化窗口会隐藏到托盘，任务继续；托盘菜单的“退出”才会结束程序。停止任务会清理正常可清理的临时文件，但强制停止不保证保留当前任务已识别的段落。

当前安装包没有代码签名。下载后可以用 PowerShell 的 `Get-FileHash -Algorithm SHA256 <安装包路径>` 与 Release 中的 `SHA256SUMS.txt` 核对文件完整性；校验值不等同于软件安全认证。

## 限制与预览状态

- 单个后台识别会话按原速送入音频，耗时通常接近录音时长，再加网络与初始化时间。
- 分段边界可能漏字、重复或影响标点，需要对照原录音校对；不会保证逐字准确，也没有说话人分离。
- 本工具自身不操作输入法界面或修改默认设备，但原生组件的资源、网络和版本行为仍可能影响使用体验；不能保证所有电脑上的兼容性。
- 当前验证范围见[发布验证记录](docs/VALIDATION.md)。尚未在第二台物理电脑上完成安装与转写验证。
- 本工具使用非公开接口，具体实现和版本限制见[架构说明](docs/ARCHITECTURE.md)。不承诺官方支持、永久可用或服务配额。

## 隐私

这不是离线工具。音频及识别所需元数据会由豆包组件交给其服务处理。本项目没有额外的上传服务器，也不随安装包分发开发者的账号配置、设备标识、录音或转写结果。

解码音频和阶段结果会短暂写入本地缓存，正常完成、失败或从界面停止后会尝试清理；断电、崩溃或文件占用可能留下缓存。原生组件自身的日志、遥测和云端留存不受本工具控制。详见[隐私说明](docs/PRIVACY.md)。
