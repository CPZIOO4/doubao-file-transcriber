在线样本由本机语音合成生成，不是真人录音，内容为：

> 你好，这是我的语音标准文件。现在正在验证录音转写助手。

实际 TXT 与上述句子一致。录音、输出和内部测试目录不进入 Git 仓库或 Release。

发布检查包括待提交文件清单、常见凭据模式和个人路径扫描、源码人工阅读、干净打包目录清单检查。安装脚本明确只收入程序、说明、许可和运行时，不收入豆包二进制、测试文件或本机账户配置。这些检查不是完整安全审计，也不验证上游原生组件的全部行为。
