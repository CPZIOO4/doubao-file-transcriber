# 1.0.0-preview.1 · 首次公开预览

拖入录音，借助本机已安装的豆包输入法组件在线识别并保存为 TXT。支持多文件排队、隐藏到托盘、兼容性检测和同名输出保护。

## 下载与使用

下载 `doubao-file-transcriber-1.0.0-preview.1-windows-x64-setup.exe`；`Source code` 是源码，不是安装程序。可用同页 `SHA256SUMS.txt` 核对文件完整性。

要求 Windows 10 1809+ / Windows 11 x64、.NET Framework 4.7.2+、可联网，以及已安装并完成首次设置的兼容豆包输入法。安装包自带 Python，无需虚拟声卡。

## 兼容范围与隐私

- 第三方实验性项目，不是豆包官方产品，也不是官方公开支持的文件转写 API。
- 目前只验证豆包输入法 0.9.0.0 的固定组件，输入法更新或服务变更可能使识别失效。
- 音频会由豆包组件发送到其在线服务，不是离线识别。项目不分发豆包组件、开发者凭据、个人录音或转写结果。
- 安装包未签名；尚未在第二台物理电脑上完成验收。

## 本轮验证

源码构建和 6 项离线回归检查通过；本机约 7 秒合成中文语音转写成功，正常结束缓存为空；GUI 启动和兼容性提示已检查。完整安装/卸载、拖拽/取消/托盘恢复及跨机体验尚未全部验收，详见 `docs/VALIDATION.md`。

使用前请阅读 README 和隐私说明，先用不含个人信息的短录音测试。报告问题时只提供必要版本和界面错误，不上传私密录音或原生日志。
