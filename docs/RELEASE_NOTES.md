# 1.2.0-preview.1 · 断点续转与均匀分段

长录音现在按总时长均匀规划切点，并在附近寻找停顿。窗口可选择 1～20 路并发任务池，默认 5 路。单段短暂失败会自动重试一次；持续失败后，再次加入未修改的同一文件只补缺失段，完整结果按原顺序拼接。未完成稿会标明缺失位置，并保留其后已完成的内容。

## 下载与使用

下载 `doubao-file-transcriber-1.2.0-preview.1-windows-x64-setup.exe`；`Source code` 是源码，不是安装程序。可用同页 `SHA256SUMS.txt` 核对文件完整性。

要求 Windows 10 1809+ / Windows 11 x64、.NET Framework 4.7.2+、可联网，以及已安装并完成首次设置的兼容豆包输入法。安装包自带 Python，无需虚拟声卡。初次使用建议从默认 5 路和非敏感短录音开始；调高任务池数量不保证线性提速。

## 兼容范围与隐私

- 第三方实验性项目，不是豆包官方产品，也不是官方公开支持的文件转写 API。
- 目前只验证豆包输入法 0.9.0.0 的固定组件，输入法更新或服务变更可能使识别失效。
- 音频会由豆包组件发送到其在线服务，不是离线识别。项目不分发豆包组件、开发者凭据、个人录音或转写结果。为续转，失败后本机 `%LOCALAPPDATA%\DoubaoFileTranscriber\Checkpoints` 会保留成功分段的文字，完整成功后自动删除，也可用界面“清除恢复缓存”手动删除。
- 安装包未签名；尚未在第二台物理电脑上完成验收。20 路真实同时识别尚未验证。

## 本轮验证

14 项离线回归覆盖均匀分段、停顿切点、单段重试、断点续转、缺口原位补齐、输入变化时不误用旧记录，以及并发顺序。使用 NASA 公开视频音轨构成的约 172 秒样本，分成 6 段（每段 28.02～29.74 秒），5 路在线转写在本机 61.85 秒完成，工作缓存与恢复缓存均清空。真实断网后的在线续转、GUI 清除按钮的点击体验、完整安装/卸载、跨机体验和 20 路真实同时识别仍需独立验收，详见 `docs/VALIDATION.md`。

使用前请阅读 README 和隐私说明，先用不含个人信息的短录音测试。报告问题时只提供必要版本和界面错误，不上传私密录音或原生日志。
