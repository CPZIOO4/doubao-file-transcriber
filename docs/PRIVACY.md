# 隐私与数据处理

## 数据去向

用户选择文件 → Windows Media Foundation 本地解码 → 本地临时 PCM 分段 → 本机豆包原生组件 → 豆包在线识别服务 → 用户指定的本地 TXT。

本项目不运营上传服务器，不嵌入开发者的账户凭据，不读取浏览器凭据或剪贴板，不打开系统麦克风。后台进程会调用豆包运行时初始化和设备标识接口，使用当前电脑生成/取得的标识及原生应用配置建立在线会话。这不等同于“不产生任何设备标识或网络请求”。

## 本地文件

- 输入录音仅供读取，不主动删除或修改。
- 输出为用户选择目录中的 TXT；同名输出自动编号。正常异常处理中已有结果可能另存为“未完成”文件。
- 缓存默认在 `%LOCALAPPDATA%\DoubaoFileTranscriber\Cache`，含解码后的音频、音频分段以及带识别文字的临时阶段记录。
- 正常完成、失败和界面停止后会尝试清理任务缓存；进程被强杀、崩溃、断电或文件占用时可能残留。退出本工具后可手动检查并删除该 Cache 目录内残留文件。
- 程序界面的历史列表仅存在于内存。原生进程标准输出/错误由父进程捕获，不主动保存为日志。
- 卸载不删除用户保存的 TXT，也不保证清除异常留下的缓存。

豆包组件内部产生的日志、遥测、设备配置及服务端留存遵循其自身行为和政策；本工具不承诺阻止或删除它们。一般文件删除不等于安全擦除。

## 公开反馈

Issue 中只提交必要的错误信息和版本。不要上传真实会议、聊天、个人录音、完整转写或原生调试日志。复现音频优先采用自行生成、无个人信息的短句。
