# 架构与适配边界

- `src/TranscriberApp.cs`：WinForms 界面、文件队列、托盘和子进程作业对象。
- `src/AudioDecode.cs`：NAudio 封装 Windows Media Foundation，解码到 16 kHz 单声道 PCM16；不播放或采集声音。
- `src/doubao_transcribe.py`：分段、后台会话超时、结果检查、重叠去重与 TXT 写入。
- `src/compatibility.py`：读取软件安装注册表项与已安装组件，核对 SHA-256；只允许已验证的组件组合。
- `src/native_worker.py`：独立进程加载用户已安装的原生组件，按固定布局创建识别会话。

## 非公开接口

这不是官方 SDK 集成示例。实现使用导出函数和针对已验证二进制重建的结构布局，并从该版本 `ImeService.exe` 的固定 RVA 读取原生配置。项目不提交这些配置的实际内容，也不分发豆包二进制。

任何组件指纹不符都应拒绝执行；不要为了兼容新版本直接移除指纹检查。更新适配必须重新确认结构布局、资源生命周期和错误处理。

当前的隔离策略不向正在运行的输入法注入代码、不补丁修改其文件、不使用输入法 RPC，不模拟键盘、焦点或剪贴板操作。加载原生运行时仍可能初始化网络、设备标识与原生日志；这些行为不能视为完全隔离。

## 分段与失败

录音按约 25–40 秒分段；连续讲话时强制切分并重叠 0.8 秒。文本去重只使用有限的前后缀匹配，因此需要人工检查边界。

每段在子进程中识别，有时限并验证送入字节数、处理返回码、结束信号和最终文本。正常异常保留之前的段落；用户强制停止整个作业不保证保留内存中的部分文本。GUI 在结束时清理本次任务目录。
